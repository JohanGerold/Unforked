# Unforked

GitHub-only, text-first contribution companion. Helps students and early contributors discover suitable repositories, understand a selected project, and identify a realistic contribution or learning path. Public repositories only. No voice or autonomous GitHub writes.

## Platform
Web: a desktop Chrome extension sidebar and optional GitHub page overlay. A browser preview exists for local evaluation. Local-first profiles and saved repositories; server-side AI credentials.

## Confirmed direction
The user chose a dark theme inspired by GitHub. Prioritize readable, compact task UI over marketing elements. Sources, uncertainty, and checked dates must be visible. Demo data must always be labeled.

## Success
A contributor can find a plausible next step and understand why it fits. The repository-summary, search, profile, save, learning-path, circle, and recovery journeys work without invented repositories or evidence.
