# Shared Local AI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run Unforked generation on the owner's Qwen3.5 4B GPU through an authenticated, bounded gateway that invited users can access through the existing backend.

**Architecture:** Hosted GitHub/auth/evidence pipeline selects Gemini or an HTTPS laptop gateway. A single-slot gateway invokes loopback Ollama; a development tunnel and owner launcher provide the connection. The extension learns provider/availability from the backend.

**Tech Stack:** Existing TypeScript, Hono, Zod, Workers/D1, React/WXT; Node24 gateway, existing esbuild, Ollama and cloudflared.

**Spec:** `docs/superpowers/specs/2026-11-01-local-ai.md`.

## Global Constraints

- Preserve invitation checks and GitHub public-read access; never send GitHub tokens to the gateway.
- Loopback11435 gateway, loopback11434 Ollama, fixedqwen3.5:4b; one active generation/two waiting;120s deadline.
- Context32768;thinkfalse;1200 output/call;30000 cumulative conservative input bytes;3000 total output;3 calls/action.
- No automatic cloud fallback, provider retries, paid upgrades, raw-prompt/output logs or credential exposure.
- Local fairness100owner/day,20friend/day,1000shared/month; preserve all Gemini allowance records and ceiling.
- Keep existing branch/demo behavior; secrets in ignored local configuration or Worker Secrets only.

## Review Focus

1. Queue cancellation/disconnect/timeout must never let queued work run later or exceed one active Ollama call.
2. Unauthorized, malformed, oversized and redirecting gateway requests must not forward credentials or arbitrary URLs/models.
3. Local usage and provider changes must not bypass invitations or reset/consume the Gemini monthly accounting.
4. Tunnel/laptop shutdown and missing configuration must produce clear offline errors with zero cloud fallback.
5. Real ranking schemas, context limits and packaging must preserve grounded output without secret/model-runtime leakage.
